# AM Check-In — คู่มือติดตั้ง (สำหรับผู้ดูแลระบบ)

ระบบเช็กอินเข้า-ออกงานด้วย GPS + เซลฟี่สด + ล็อกเครื่อง ใช้ **GitHub Pages** (โฮสต์หน้าเว็บ ฟรี) + **Firebase** (ล็อกอินและฐานข้อมูล ฟรีแพ็กเกจ Spark ไม่ต้องผูกบัตร)
ทำทั้งหมดผ่านเว็บเบราว์เซอร์ ไม่ต้องติดตั้งโปรแกรม — ใช้เวลาประมาณ 30–40 นาที

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `app.js` | หน้าเช็กอินของพนักงาน |
| `admin.html`, `admin.js` | หน้าหัวหน้า: รายงาน, พนักงาน, สาขา, อนุมัติเครื่อง |
| `firebase-config.js` | **ต้องแก้** — ใส่ค่า Firebase และอีเมลผู้ดูแล |
| `firestore.rules` | **ต้องแก้แล้ววางใน Firebase** — กฎความปลอดภัยฝั่งเซิร์ฟเวอร์ |
| `common.js`, `style.css`, `manifest.json`, `icons/` | ไฟล์ประกอบ ไม่ต้องแก้ |

---

## ขั้นที่ 1 — สร้างโปรเจกต์ Firebase

1. เข้า https://console.firebase.google.com → **Create a project** → ตั้งชื่อ เช่น `am-checkin` (ปิด Google Analytics ได้)
2. หน้าโปรเจกต์ กดไอคอน **`</>` (Web)** → ตั้งชื่อแอป → **Register app**
3. คัดลอกค่าในก้อน `firebaseConfig` (apiKey, authDomain, projectId ...) ไปวางแทนใน `firebase-config.js`
4. ใน `firebase-config.js` แก้ `OWNER_EMAIL` เป็นอีเมลของคุณ (อีเมลที่จะใช้เข้าหน้าหัวหน้า)

## ขั้นที่ 2 — เปิดระบบล็อกอิน

1. เมนูซ้าย **Build → Authentication → Get started**
2. แท็บ **Sign-in method** → เลือก **Email/Password** → Enable → Save
3. แท็บ **Users → Add user** → ใส่อีเมล (ตรงกับ `OWNER_EMAIL`) และรหัสผ่านของคุณ
4. แท็บ **Templates** → กดไอคอนดินสอ → **Template language: Thai** (อีเมลลืมรหัสผ่านจะเป็นภาษาไทย)

## ขั้นที่ 3 — สร้างฐานข้อมูล + ใส่กฎความปลอดภัย

1. **Build → Firestore Database → Create database**
2. Location: **asia-southeast1 (Singapore)** → เลือก **Start in production mode** → Create
3. แท็บ **Rules** → ลบของเดิมทั้งหมด → วางเนื้อหาไฟล์ `firestore.rules`
4. แก้บรรทัด `return 'your-email@example.com';` เป็นอีเมลของคุณ (ตรงกับ `OWNER_EMAIL`) → **Publish**

## ขั้นที่ 4 — นำขึ้น GitHub Pages

1. สมัคร/ล็อกอิน https://github.com → มุมขวาบน **+ → New repository** → ชื่อ เช่น `checkin` → **Public** → Create
2. กด **uploading an existing file** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `icons`) ลงไป → **Commit changes**
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/checkin/`
5. กลับไป Firebase → **Authentication → Settings → Authorized domains → Add domain** → ใส่ `<ชื่อผู้ใช้>.github.io`

> ลิงก์พนักงาน: `https://<ชื่อผู้ใช้>.github.io/checkin/`
> ลิงก์หัวหน้า: `https://<ชื่อผู้ใช้>.github.io/checkin/admin.html`

## ขั้นที่ 5 — ตั้งค่าเริ่มใช้งาน (ในหน้าหัวหน้า)

1. เปิด `admin.html` → ล็อกอินด้วยอีเมลเจ้าของ (ระบบสร้างสิทธิ์ผู้ดูแลให้อัตโนมัติ)
2. **แท็บสาขา** → กด **"ใส่รายชื่อ 14 สาขาของผม"** → **นำเข้า** (ได้รหัส + ชื่อสาขาครบ 14 สาขา)
3. เติม **พิกัด** ทีละสาขา: กด "แก้ไข" → วางพิกัดจาก Google Maps (กดค้างที่อาคาร → คัดลอกตัวเลข) → บันทึก
   ⚠️ สาขาที่ยังไม่มีพิกัด จะไม่แสดงให้พนักงานเลือก
4. **แท็บพนักงาน** → เพิ่มทีละคน หรือวางรายชื่อหลายคนพร้อมกัน → ระบบแสดงอีเมล/รหัสผ่านเริ่มต้นให้นำไปแจ้งพนักงาน
5. ส่งข้อความคู่มือพนักงาน (ไฟล์ `คู่มือพนักงาน`) พร้อมลิงก์ให้ทีม

## งานประจำของหัวหน้า

- **รายงานเข้า-ออก**: เลือกช่วงวันที่/สาขา → ดูรูปเซลฟี่ (กดที่รูปเพื่อขยาย ตรวจว่าทำท่าตรงกับที่ระบบสุ่ม) → Export CSV เปิดใน Excel ได้ทันที
- **คำขอเปลี่ยนเครื่อง**: พนักงานเปลี่ยนมือถือ / ล้างข้อมูลเบราว์เซอร์ / ใช้คอมพิวเตอร์ → อนุมัติหรือปฏิเสธ
- **พนักงานลาออก**: กด "ระงับ" (ไม่ต้องลบ ข้อมูลย้อนหลังยังอยู่)
- **ทุก 2–3 เดือน**: แท็บตั้งค่า → ลบรูปเก่ากว่า 90 วัน (ประหยัดพื้นที่ฟรี 1 GB)

## ระบบป้องกันอะไรได้บ้าง

| การโกง | ป้องกันโดย |
|---|---|
| เช็กอินจากบ้าน | GPS ต้องอยู่ในรัศมีสาขา — ตรวจซ้ำที่เซิร์ฟเวอร์ (rules) ไม่ใช่แค่หน้าเว็บ |
| ปรับเวลาในเครื่อง | ใช้เวลาเซิร์ฟเวอร์ Firebase เท่านั้น |
| ส่งรูปเก่า | เปิดได้เฉพาะกล้องสด ไม่มีปุ่มเลือกรูป + ท่าสุ่มทุกครั้ง + ประทับชื่อ/ท่า/เวลาบนรูป |
| ฝากเพื่อนเช็กอิน | 1 บัญชีผูก 1 เครื่อง เปลี่ยนเครื่องต้องให้หัวหน้าอนุมัติ |
| แก้/ลบประวัติ | พนักงานแก้หรือลบรายการย้อนหลังไม่ได้ |

## ข้อจำกัดที่ควรรู้ (บอกตรง ๆ)

- **GPS ปลอม**: มือถือที่ติดตั้งแอปปลอมตำแหน่ง (Fake GPS / เครื่องเจลเบรก) ยังหลอกได้ — หัวหน้าควรสุ่มตรวจรูปเซลฟี่ว่าฉากหลังเป็นสาขาจริง
- **ท่าสุ่ม** ระบบไม่ได้ตรวจด้วย AI — หัวหน้าเป็นผู้ตรวจจากรูป
- **ผูกเครื่อง** ใช้รหัสที่เก็บในเบราว์เซอร์ ถ้าพนักงานล้างข้อมูล Safari/Chrome ต้องขออนุมัติเครื่องใหม่ (เป็นเรื่องปกติ)
- **ฟรีแพ็กเกจ**: อ่าน 50,000 / เขียน 20,000 ครั้งต่อวัน, พื้นที่ 1 GB — ทีม 50 คนใช้ได้สบาย
- ระบบนี้เป็นเครื่องมือของทีม ไม่ได้เชื่อมกับระบบ HR ของบริษัท หากจะใช้แทนการลงเวลาทางการ ควรแจ้ง HR / ผู้บังคับบัญชาก่อน และแจ้งพนักงานว่าระบบเก็บตำแหน่ง+รูปถ่าย (PDPA)
